Project / Engineering

Five stages, each forced by the last

Every stage below is read the same way: what it took in, what it produced, what the run revealed, and what that forced in the next one. The amber line carries the number that changed the design. None of them arrived as an error message — each came from reading results that had already been accepted.

In each strip a filled block was executed and a hollow block was written but never run. Strips are not to scale: the stages operate on pools five orders of magnitude apart.

1.1 — The first funnel

The first pipeline asked one question — from a set already annotated as antioxidant, which peptides are safe enough to build a fusion around — and answered it in one direction only: 656 removed for predicted toxicity, 1,077 for allergenicity and 3 for haemolysis. A curated set is not a safe set. The remaining phases were written and not run, because a run whose ceiling is a few hundred constructs was not worth the hours it would take.

1.2 — The first complete run

Two findings came out of reading the stored results as arithmetic rather than as output. The safety coefficients — 0.13, 0.09 and 0.05 — were each smaller than the activity weight they were meant to override, so a peptide with a severe haemolysis signal could still finish near the top. And the composite used in the later rounds still carried the functional score at its largest coefficient, which meant the control arm was being ordered by the property that defined it as the control. Neither produced a failure.

1.3 — The scale step

Three rounds of enlarging the labelled sets had returned less each time, so the requirement was dropped and the sequence universe was screened instead of a curated catalogue. That changed what the pool was made of: a reference proteome loses 99.7% of its entries to a thirty-residue ceiling, while a metagenomic catalogue of predicted small proteins loses 97% and supplies almost everything that survives. The pool became large and almost entirely unannotated — a real cost, accepted because a sequence nobody has studied can still be synthesised and tested, whereas a label that does not exist cannot be invented.

1.4 — Hierarchical filtering

One criterion per round, safety as a veto, and a single weighted average whose weights come from the data. The final score is structure only — surface exposure, aggregation propensity and structural confidence — with no activity term anywhere in it. The consequence reads at first like a mistake: the eight highest-scoring constructs in the entire run come from the control arm. It is in fact the proof that the two arms are independent, and it changed the instruction we would give a wet lab.

2.0 — The platform

Before the four runs, every tool was reproduced from its authors' code, its decision logic read, and several were retrained in an attempt to improve them. The gains were marginal and the same defects reappeared under a different representation, which puts the problem in the benchmark rather than in the model. The tools were therefore reclassified by what each can actually support — three can eliminate a candidate, two can rank, one ranks weakly, the rest only inform — and functional selection moved from a probability threshold to an in-pool percentile.

Four runs produced 496 constructs across four directions. Two of those directions ship as pending signatures rather than as results, because the only available model answers whether a sequence resembles a known functional peptide rather than whether it has the activity. That distinction is carried in the data and in the interface rather than smoothed over: 198 of the 496 constructs carry no immunogenicity value from either pathway, and an unmeasured gate is reported as indeterminate — never as a pass, and never as a zero.

Four rules that came out of it

A precondition is a threshold, never a weightA coefficient small enough to be a fair weight is also small enough to be outvoted.
A score that cannot separate candidates is not evidenceA constant given a coefficient becomes noise in every decision downstream of it.
A published boundary belongs to its authors' populationRe-establish it on the population being screened. This is checkable before any biology is discussed.
Scarcity of data sets the ceiling, not model capacityWhere labels are absent, the useful move is to change the question rather than to train harder.

What this does not establish

No construct has been shown to be active. Every functional number is a prediction from a model trained on other data, and the wet-lab comparison that would test the premise of the design — that the two arms behave differently — has not been run. Structural confidence averages 0.42 on a scale where 0.50 marks the edge of meaningful confidence, a property of silk's glycine-alanine repeats rather than of the predictor, so the ranking built on those structures orders imperfect models consistently and does not measure them.
